# Бизнес-процессы Docsvision

- `Scripts/DeliveryProcess.cs` — программный узел регистрации и уведомлений, цикл через 2 минуты.
- `Scripts/ArchiveProcess.cs` — программный узел архивирования, запуск в 00:00 МСК.
- `AgoraOutgoingWorkflow` — прикладные обработчики, контекст, блокировки, права и миграция штатных объектов.

Коды узлов используют прямые вызовы `ProcessHandlers`. В свойствах программного узла подключается `C:\AGORA-OUT\csharp-runtime\Agora.Outgoing.Workflow.dll`.

`Agora.Outgoing.Runner.exe migrate` обновляет существующие объекты, `inspect-processes` сохраняет их аудит, `migrate-client` обновляет сценарий Windows-клиента. Перед использованием должны быть подготовлены база, метаданные, учётные записи и конфигурация стенда. Пример идентификаторов — в `Install/Configuration`.

Отключённые дублирующие задания регистрации, уведомлений и архива включать не требуется: расписанием управляет Workflow. Инфраструктурные задания прав доступа, CRL и SMTP запускают C# EXE.
