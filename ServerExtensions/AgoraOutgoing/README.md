# Web-расширение АГОРА

`AgoraOutgoingServerExtension` содержит регистрацию серверного расширения, MVC-контроллер и модель запроса. Используется API Web-клиента 5.5 с текущим объектным контекстом пользователя.

`AgoraOutgoingWebExtension` содержит только TypeScript-исходники, CSS и инструменты сборки. Входная точка `src/Index.ts` регистрирует три группы обработчиков событий. Бизнес-операции выполняет C# на сервере.

Нативные разметки размещены в `Install/WebLayouts/AgoraOutgoing` от корня репозитория. Копирование результатов сборки не меняет привязки событий: имена `AgoraOpened`, `AgoraSaving`, `AgoraSaved` и остальных команд сохранены.

Команды сборки и требования к локальному SDK описаны в корневом README.
